# 报备 (BeiAn)

纯本地 Android 应用：记录行动轨迹、查看历史轨迹，并展示设备状态（电量、
屏幕使用时间、解锁次数、网络状态）。所有数据仅保存在本机，不上传。

## 功能

- 实时轨迹记录（前台服务 + Fused Location）
- 地图展示当日 / 历史轨迹（OpenStreetMap，无需 Key）
- 历史轨迹按天回看
- 设备状态：电量、屏幕使用时间、解锁次数、亮屏次数、网络状态
- 导出当日报备为文本文件，手动分享

## 构建

```bash
./gradlew assembleDebug
```

APK 输出：`app/build/outputs/apk/debug/app-debug.apk`

## 地图

使用 OpenStreetMap 瓦片，无需 API Key。首次加载瓦片需要联网，
之后瓦片会缓存在本地。

## 权限说明

| 权限 | 用途 |
|---|---|
| 定位（含后台） | 记录轨迹 |
| 前台服务 | 持续采集不中断 |
| 使用情况访问 | 读取屏幕使用时间 |
| 通知 | 显示记录中的常驻通知 |
| 网络状态 | 展示当前网络 |

## 隐私

数据全部写入本机 Room 数据库与 DataStore，不进行任何网络上传。
